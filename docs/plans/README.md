# Build plans

Written before each stage was built, and kept as written (process evidence). Each plan lists its tasks,
tests and the interfaces between tasks; deviations made while building are noted in the commit history.
Later plans supersede earlier details (e.g. the package was renamed `fpp/` → `roomscan/` after Plan 1).

1. `plan1-lidar-single-room.md` — LiDAR tier, one room, end to end
2. `plan2-rooms-and-drift.md` — rooms, adjacency, drift correction
3. `plan3-video-tier.md` — video tier
4. `plan4-photo-tier.md` — photo tier and stitching
5. `plan5-damage-and-scope.md` — damage, concealed-damage rules, repair scope
